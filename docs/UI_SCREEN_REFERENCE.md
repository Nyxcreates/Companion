# Companion UI Screen Reference

Version: 1.0

This document defines every screen inside Companion.

These layouts are the source of truth.

Developers should never invent new layouts unless approved.

Every screen should follow the Design System.

====================================================
GLOBAL UI RULES
====================================================

✓ Glassmorphism

✓ Rounded Cards

✓ Soft Shadows

✓ Smooth 60 FPS animations

✓ Minimal Text

✓ Spacious Layout

✓ Dark Mode First

✓ Responsive

✓ Animated Backgrounds

✓ Character Always Visible

✓ Ambient Music (Optional)

Every page should feel alive.

====================================================
FINAL DESIGN RULE
====================================================

Every screen should answer one question:

"If this screen were shown without text,

would someone still recognize it as Companion?"

If not,

redesign it.

Companion should have a unique identity that cannot be mistaken for another productivity application.
