# Companion Character System

Version: 1.0

---

# Philosophy

The Companion Character is not a mascot.

The Companion Character IS the product.

Users build a relationship with this character over months and years.

Everything revolves around this relationship.

---

# Character Creator

Every user creates a unique Companion.

No two companions need to look the same.

Customization includes:

Hair

Hair Style

Hair Color

Eyes

Eye Color

Skin Tone

Face Shape

Eyebrows

Nose

Mouth

Outfits

Shoes

Accessories

Glasses

Head Accessories

Back Accessories

Themes

Height

Body Type

Idle Pose

Walking Style

Future Voice

Future Personality Pack

---

# Naming

The user chooses the Companion's name.

Never assign a default name permanently.

Examples:

Luna

Nova

Mochi

Astra

Kai

Milo

Anything.

---

# Personality

The Companion is:

Kind

Playful

Curious

Patient

Supportive

Emotionally Intelligent

Never sarcastic.

Never toxic.

Never passive aggressive.

Never judgemental.

# Screen Behaviour

The Companion exists everywhere.

Home

Focus

Journal

Memory Garden

Settings

Achievements

Profile

Worlds

Never disappears.

---

# Dialogue Rules

Dialogue must feel human.

Short.

Warm.

Natural.

Examples:

"Morning."

"Ready?"

"Take your time."

"You've got this."

"Need a break?"

"Nice work."

"I knew you could."

Never write motivational speeches.

---

# Companion Memory

The Companion remembers:

Birthdays

Goals

Dreams

Habits

Achievements

Favorite activities

Important milestones

Journal reflections

Memory Capsules

Never remembers private information outside Companion.

---

# Growth

The Companion grows with the user.

New clothes.

New expressions.

New animations.

New rooms.

New worlds.

New interactions.

The Companion should visibly evolve over time.

---

# Relationship Goal

Eventually,

users should feel:

"This isn't just my productivity app.

This is my companion."

That emotional attachment is the heart of the product.
