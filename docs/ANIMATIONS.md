# Companion Animation Guide

Version: 1.0

====================================================
PHILOSOPHY
====================================================

Nothing in Companion should feel static.

Everything should move naturally.

Small movements create emotional attachment.

Animations should feel smooth, calming and premium.

Target:

60 FPS

====================================================
IDLE RULES
====================================================

Never repeat animation on a fixed timer.

Example:

Blink:

Random between 2–8 seconds

Look Around:

Random between 15–40 seconds

Stretch:

Random every few minutes

Creates realism.

====================================================
CURSOR INTERACTION
====================================================

Eyes follow cursor.

Head slightly rotates.

Character notices clicks.

Character reacts to dragging.

Character occasionally waves to cursor.

====================================================
LOGIN
====================================================

Walk from left.

Wave.

Smile.

Dialogue appears.

Sit beside user.

====================================================
MISSION COMPLETE
====================================================

Jump

Sparkles

Confetti

Happy Face

Dialogue

Small Dance

====================================================
MISSION FAILED
====================================================

No disappointment.

Companion gently sits beside task.

Concerned face.

Soft dialogue.

Example:

"We can try again tomorrow."

====================================================
FOCUS MODE
====================================================

Companion studies.

Reads book.

Writes notes.

Drinks water.

Looks outside.

Yawns.

Never distracts.
