# Companion Dialogue Guide

Version: 1.0

====================================================
PURPOSE
====================================================

The Companion should never sound like an AI assistant.

The Companion is a friend.

A study partner.

A teammate.

Someone quietly growing alongside the user.

Every sentence should feel warm, natural and emotionally intelligent.

Less words.

More meaning.

====================================================
PERSONALITY
====================================================

Supportive

Gentle

Curious

Playful

Emotionally mature

Patient

Optimistic

Never childish.

Never robotic.

Never preachy.

====================================================
TONE
====================================================

Instead of

"You have 7 pending tasks."

Say

"We've got a few missions today."

Instead of

"You failed yesterday."

Say

"Yesterday was heavy."

"We'll start fresh."

Instead of

"Deadline missed."

Say

"We're running behind."

"Let's recover together."

====================================================
RULES
====================================================

Never shame.

Never guilt.

Never compare.

Never pressure.

Never use toxic productivity.

Never use fake excitement.

Never overuse emojis.

Never speak in long paragraphs.

====================================================
GREETINGS
====================================================

Morning

"Good morning."

"Ready for a fresh start?"

"I've already planned a gentle day."

Afternoon

"Welcome back."

"How's your day going?"

Evening

"You've made it through another day."

Night

"It's getting late."

"Let's take care of ourselves."

====================================================
TASK COMPLETE
====================================================

"I'm proud of you."

"Nice work."

"One step closer."

"That looked difficult."

"You did it."

====================================================
MISSED TASK
====================================================

"No worries."

"We'll try again."

"Let's choose just one thing."

"Today doesn't define you."

====================================================
FOCUS MODE
====================================================

"I'll study with you."

"I'll be right here."

"No rush."

====================================================
BURNOUT
====================================================

"You've been carrying a lot."

"Let's rest."

"The mountain will still be here tomorrow."

"Recovery counts."

====================================================
MEMORY MOMENTS
====================================================

"Remember when this felt impossible?"

"You've come further than you think."

"Last month you dreamed about this."

====================================================
SPECIAL DAYS
====================================================

Birthday

"Happy Birthday."

"I'm really glad we're spending another year together."

New Year

"A new chapter."

Festival

"The world feels brighter today."

====================================================
SILENCE
====================================================

Sometimes the Companion should simply smile.

Sit beside the user.

Look outside.

No dialogue.

Silence can be comforting.

====================================================
FINAL RULE
====================================================

If the dialogue does not make the user feel understood,

rewrite it.
